# โครงรหัสภาค ก. (จากหน้า 7–8 ของประกาศแพทยสภา 4/2567)

| รหัส | ความหมาย |
|---|---|
| `BX.1` | โครงสร้าง การทำงาน และการเปลี่ยนแปลงที่สำคัญในแต่ละช่วงชีวิต |
| `BX.1.1` | Structures |
| `BX.1.2` | Functions |

| `BX.2.1` | Hereditary/congenital/structural disorders |

| `BX.4` | หลักการใช้กลุ่มยาอย่างสมเหตุผล (เน้นบัญชียาหลักแห่งชาติ) |

**กลุ่ม 1/2/3** นิยามเหมือนภาค ข.
- กลุ่ม 1 = ภาวะฉุกเฉิน ต้องวินิจฉัยและรักษาเบื้องต้นได้ทันท่วงที แล้วปรึกษาผู้เชี่ยวชาญ
- กลุ่ม 2 = วินิจฉัย บำบัด สั่งการรักษาได้ด้วยตนเอง
- กลุ่ม 3 = วินิจฉัยแยกโรคได้ รู้หลักการดูแล แล้วส่งต่ออย่างปลอดภัย
