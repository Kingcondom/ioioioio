# attic — ของที่ถูกแทนที่ไปแล้ว แต่ยังไม่ทิ้ง

โฟลเดอร์นี้ **ไม่ได้ publish** ขึ้น artifact และ **ไม่ได้อยู่ใน `data/`**
โดยตั้งใจ — `tools/checkdata.py` จะ glob `data/*.json` ทั้งหมด ถ้าเอาไฟล์
พวกนี้ไปวางใน `data/` รหัสหัวข้อจะชนกับคาบที่ใช้งานจริงทันที

เก็บไว้เพราะกฎในมือ: ของสำคัญต้องมีอยู่อย่างน้อย 2 ที่ ไฟล์ในนี้คือฉบับที่
**ไม่เหลืออยู่ที่อื่นแล้ว** ลบได้ก็ต่อเมื่อเจ้าของบอกเองว่าไม่ต้องการ

## chest-asthma-CH-AST-superseded.json

คาบ Asthma (`lec` = `3/11`) ฉบับ **11 หัวข้อ · 25,609 ตัวอักษร · 32 ข้อ**
รหัสข้อสอบขึ้นต้น `CH-AST-MCQ-` — เคยเป็นฉบับที่ใช้งานจริง และเป็นฉบับที่
commit `fa12626` เลือก *เก็บไว้* ตอนตัดสินคาบ asthma ที่ซ้ำกันสองฉบับ

ต่อมาเจ้าของสั่งให้ทำคาบ asthma ใหม่ทั้งคาบ ("คนสอง ทำใหม่เลย เนื้อหา
asthma") อีกเซสชันจึงเขียนขึ้นใหม่หมดเป็น **13 หัวข้อ · 32,768 ตัวอักษร ·
30 ข้อ** รหัส `CH-ASTH-MCQ-` แล้ว publish ทับของเดิม

สองฉบับนี้ **ไม่ใช่เวอร์ชันของกันและกัน** — รหัสข้อสอบไม่ซ้ำกันแม้แต่ข้อเดียว
ที่รหัสหัวข้อชนกัน (`chest-ast-01` … `chest-ast-11`) เพราะต่างคนต่างนับหนึ่ง
ใหม่เท่านั้น ถ้าเอา live มาทับ repo ตรง ๆ โดยไม่เก็บไฟล์นี้ไว้ก่อน เนื้อหา
ฉบับเดิมจะหายไปโดยไม่เหลือที่ไหนเลย

ของที่มีเฉพาะในฉบับเดิมและไม่ได้ยกมาในฉบับใหม่ เช่น
- หัวข้อ 9 ดูแลระยะยาว — วง **Assess · Adjust · Review** และหลักจำ **I ADORE**
- หัวข้อ 10 เกณฑ์ **92/30/50** และเกณฑ์จำหน่าย **1–2/92/70**

ถ้าจะกู้กลับ: อ่านไฟล์นี้แล้ว append เข้า `data/chest.json` โดย **ต้องเปลี่ยน
รหัสหัวข้อและรหัสข้อสอบก่อน** ไม่งั้นชนกับคาบ asthma ที่ใช้อยู่
