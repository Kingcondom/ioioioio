## ตรวจอะไร
- ข้อเท็จจริง ค่าตัด ขนาดยา ยาตัวแรก ตามแนวทางปัจจุบัน (ถึงปี 2025–2026: ESC/AHA/ACC, KDIGO, GINA, GOLD, ADA, IDSA/CDC, WHO, แนวทางไทย)
- โจทย์ synth: มีคำตอบที่ดีที่สุดเพียงข้อเดียวจริงไหม, ตัวลวงข้อใดถูกพอๆ กันไหม, ตัวเลข lab/vital สอดคล้องกันไหม (คำนวณ anion gap, Winter, osmolality, corrected Ca ฯลฯ เองด้วย python), คำตอบตรงกับ explain ไหม
- ภาษาไทยอ่านรู้เรื่อง ไม่กำกวมจนเข้าใจผิด
- ไม่ต้องแก้สำนวนที่ถูกอยู่แล้ว เน้นสิ่งที่ผิดหรือเสี่ยงทำให้เข้าใจผิด

## วิธีแก้
- แก้ใน out2/<sys>.json โดยตรง (ใช้สคริปต์ python โหลด-แก้-เขียนกลับ) คงโครงสร้างเดิม คำตอบที่ถูกของ synth ต้องอยู่ choices[0]
- ถ้าโจทย์ synth มีปัญหาจนต้องเปลี่ยนคำตอบ ให้เขียนใหม่ทั้ง stem/choices/explain ให้ถูก
- หลังแก้รัน `python3 check2.py <sys>` ต้องขึ้น OK
- ปัญหาของข้อรูป: เขียนลง `review/<sys>_pics_fix.json` = [{"id": "...", "problem": "...", "fix": "ข้อความแก้ไขภาษาไทยที่จะแสดงให้ผู้อ่าน"}] (ไม่มีปัญหาให้เขียน [])
- บันทึกทุกการแก้ใน `review/<sys>.md` เป็นรายการ: ตำแหน่ง (เช่น synth SYN-CARDIO-03 explain / one_per_theme "<theme>" related / fix), ระดับ (ผิดร้ายแรง = จะทำให้ตอบข้อสอบผิดหรือรักษาผิด / ผิดเล็กน้อย / ปรับให้ชัด), ก่อน → หลัง สั้นๆ
