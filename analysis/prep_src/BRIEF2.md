# งาน: ชุด "แก่นละ 1 ข้อ" + "โจทย์รวบยอด" สำหรับเตรียมสอบ MED421 (อายุรศาสตร์ ป.4–5) และ NL

โฟลเดอร์งาน: /tmp/claude-0/-home-user/347a4502-c25a-5e77-97d4-8abdcb942e77/scratchpad
Input ต่อระบบ:
- `in2/<sys>_themes.json` = แก่นของข้อสอบเก่า (จากโพย MED28–35) แต่ละแก่นมี `theme`, `theme_years` (รุ่นที่เคยออก), `rep_id` (ข้อตัวแทนที่คัดไว้แล้ว: ออกหลายรุ่นสุด/ล่าสุด), `items` (ทุกข้อในแก่นพร้อมโจทย์ ตัวเลือก คำตอบ และ `note` คำอธิบายเดิมภาษาไทย)
- `in2/<sys>_nlgaps.json` = หัวข้อในเกณฑ์แพทยสภา NL 2567 ของระบบนี้ที่ "ไม่เคยออกในโพย" หรือ "แตะแค่บางส่วน"

## ส่วนที่ 1: one_per_theme (ทุกแก่น แก่นละ 1 รายการ)
- `theme`: ชื่อแก่นตรงตัวอักษร
- `id`: ใช้ `rep_id` เป็นหลัก เปลี่ยนเป็นข้ออื่นในแก่นได้เฉพาะเมื่อ rep_id ไม่มีตัวเลือกที่ดีหรือคำถามแคบเกินไป
- `related`: **"เนื้อหาที่เกี่ยวข้องที่ต้องรู้"** ภาษาไทย (ศัพท์แพทย์อังกฤษได้) เป็น markdown bullet 4–8 ข้อ (ขึ้นต้นด้วย "- ")
  - เอามุมที่ข้ออื่นในแก่นเดียวกันเคยถาม (เพราะข้อเหล่านั้นจะไม่ได้ทำ) มาสรุปให้ครบ
  - เติมสิ่งที่ต้องรู้ต่อจากเรื่องนี้ ที่น่าจะถูกถามมุมใหม่: เกณฑ์/ค่าตัด, ยาตัวแรกและขนาดสำคัญ, ข้อห้าม, ภาวะแทรกซ้อน, pitfall, วิธีแยกจากโรคที่สับสน
  - ไม่ต้องอธิบายซ้ำกับ note ของข้อตัวแทน
  - ใช้ **ตัวหนา** เน้นคำสำคัญได้ (markdown `**`) ห้ามใช้ heading
- `fix` (ใส่เฉพาะเมื่อจำเป็น): ถ้าคำตอบของข้อตัวแทนไม่ตรงแนวทางปัจจุบัน ให้เขียนสั้นๆ ว่าที่ถูกคืออะไร

## ส่วนที่ 2: synth (โจทย์รวบยอดใหม่)
เป้าหมาย: **จำนวนข้อน้อยที่สุด แต่ครอบคลุมมากที่สุด** แต่ละข้อรวมหลายแก่นที่เป็นเรื่องเดียวกัน/ต่อเนื่องกัน และเติมหัวข้อ NL ที่ยังไม่เคยออก
- ทุกแก่นใน input ต้องอยู่ใน `covers_themes` ของอย่างน้อย 1 ข้อ และทุกหัวข้อใน nlgaps ต้องอยู่ใน `covers_nl` ของอย่างน้อย 1 ข้อ
- ขนาดเป้าหมาย: ข้อละ 2–6 แก่น (เรื่องเดี่ยวที่ไม่เข้ากับอะไรเลยรวมกับเรื่องใกล้เคียงได้ หรือรวมหัวข้อ NL gap เข้ากับแก่นที่ใกล้ที่สุด) จำนวนข้อโดยประมาณ = จำนวนแก่น ÷ 3 บวกเล็กน้อย
- รูปแบบแต่ละข้อ:
  - `id`: "SYN-<SYS>-01" … (SYS = ตัวพิมพ์ใหญ่ของชื่อระบบ)
  - `title`: ชื่อเรื่องสั้นภาษาไทยปนอังกฤษ
  - `stem`: โจทย์ภาษาอังกฤษ เคสผู้ป่วยสมจริง มีตัวเลข lab/vital ที่สอดคล้องกันจริง (ตรวจเลขเอง) ถามคำถามเดียวแบบ single best answer ที่ต้องใช้ความเข้าใจทั้งเรื่องจึงตอบได้
  - `choices`: 5 ตัวเลือกไม่ซ้ำ **คำตอบที่ถูกอยู่ choices[0] เสมอ** และ `answer: 0` (ระบบจะสลับเอง) ตัวลวงแต่ละตัวควรเป็นแก่นอื่นในกลุ่มเดียวกัน เพื่อให้ข้อเดียวทบทวนได้หลายเรื่อง
  - `explain`: ภาษาไทย ไล่กลไกก่อน แล้วบอกว่าทำไมข้อถูกถูก และตัวลวงแต่ละตัวผิดเพราะอะไร (ใช้กับโจทย์เรื่องไหนได้)
  - `fullcover`: ภาษาไทย markdown **สรุปทั้งเรื่องในข้อเดียว** ใช้ bullet ("- ") 8–14 ข้อ ครอบคลุม วินิจฉัย / กลไก / การสืบค้นและค่าตัด / การรักษาและยาตัวแรก / ภาวะแทรกซ้อนและ pitfall และขึ้น bullet ด้วย "**ยังไม่เคยออก:** …" สำหรับประเด็นจาก NL gap หรือมุมที่โพยยังไม่เคยถาม
  - `pearl`: 1 บรรทัดจำง่าย
  - `covers_themes`: รายชื่อแก่นตรงตัวอักษร
  - `covers_nl`: รายชื่อ `topic` จาก nlgaps ตรงตัวอักษร (ว่างได้ `[]`)

## มาตรฐานเนื้อหา
- ยึดแนวทางปัจจุบัน (เช่น ESC/AHA, KDIGO, GINA/GOLD ล่าสุด, แนวทางไทย) ถ้าโพยเก่าตอบไม่ตรงแนวทาง ห้ามลอกตาม ให้แก้และบอกไว้
- ภาษาไทยอ่านง่าย ประโยคสั้น ไม่ใช้ " · " คั่นรายการ
- ห้ามแต่งตัวเลข/ค่าตัดที่ไม่แน่ใจ ถ้าไม่แน่ใจให้เขียนในเชิงหลักการ
