- `refs/nl_2567.json` ตอนนี้มี 250 หัวข้อ ครอบคลุม **B4 ผิวหนัง · B5 กระดูกและข้อ · B6 ระบบหายใจ · B7 หัวใจ · B9 ไต** และหมวดคลินิก 2.1/2.2/2.3/3.x เท่าที่ใช้ไปแล้ว
- ระบบที่ยังไม่ทำต้องไปคัดเพิ่มจาก `NL_Syllabus_2567_text.md`: **B1–B3 (เลือด/ภูมิคุ้มกัน, ระบบประสาท), B8 (ทางเดินอาหาร), B11–B12 (ต่อมไร้ท่อ ฯลฯ)** และหมวด 2.3 ของระบบนั้น ๆ

- โพย MED28–34 มีหน้าที่ฟอนต์เพี้ยนสองแบบ: **บรรทัด ~6794–10058 (MED30)** อังกฤษ/ไทยกลายเป็นอักษรละตินขยาย/ซีริลลิก และ **บรรทัด ~10380–10803 (MED29)** ไทยเป็นรหัส TIS-620 ที่ถูกเลื่อน — `export_meq_osce.py` มีตัวถอด (`decode_cyr`, `decode_tis`) ถ้าจะสกัด MCQ จากช่วงนี้ให้ใช้ตัวถอดเดียวกัน
