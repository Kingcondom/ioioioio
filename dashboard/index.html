ทุกคาบบรรยาย MED

ตารางบรรยายของกลุ่มเราทั้งหมด เรียงตามวันจริงจากปฏิทิน แต่ละคาบมีปุ่มเปิด Learn (บทเรียน + ข้อเช็คความเข้าใจ) และ Drill (ข้อสอบใหม่ + คลังเก่า MED28–35) ตรงคาบนั้นทันที

MED421 learn เปิด MED421 Ward Drill เปิด ห้องสมุดท่าอาจารย์ บทข้างเตียง

ความครอบคลุมรายระบบ
