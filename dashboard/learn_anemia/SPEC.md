# งาน: บท "Anemia — pathophysiology แบบไล่กลไก 21 ภาวะ" ใน MED421 learn

ผู้ใช้ (นักศึกษาแพทย์ปี 4 ไทย เตรียมสอบลงกองอายุรศาสตร์และ NL) ขอให้เพิ่มบทนี้ใน Learn
โดยขอ **"ทริคจำของสากล และ pathophysiology แบบตึง ๆ"** (ลึก ละเอียด ไล่กลไกครบ)
แรงบันดาลใจจากโพสต์สรุปภาวะซีด 21 ภาวะของเพจ Nakorn - Core Physiology แต่เราเขียนใหม่เองทั้งหมด (ห้ามลอก)

คุณทำ **กลุ่มเดียว** ตามคำสั่ง: 1 section ต่อ 1 ภาวะ (+ section ภาพรวมถ้าได้รับมอบ)

## ส่งงาน 2 ไฟล์
1. `OUT/sec_<G>.json` = list ของ section (รูปแบบด้านล่าง) — ตรวจ: `cd TOOLS && python3 learn_lesson_tool.py check BASE OUT/sec_<G>.json`
2. `OUT/anim_<G>.json` = ภาพเคลื่อนไหว + หลักจำ ตามรูปแบบใน `ANIMSPEC` (อ่านไฟล์นั้นทั้งไฟล์ กติกา SVG/ขั้นตอน/การตรวจอยู่ในนั้น)
   - ตรวจ anim ต้องมีข้อมูลที่ใส่ section ของคุณแล้ว:
     `cd TOOLS && python3 learn_lesson_tool.py assemble BASE HEADER WORK/<G>/data OUT/sec_<G>.json`
     แล้ว `python3 anim_tool.py check WORK/<G>/data OUT/anim_<G>.json`
     และ `python3 anim_tool.py preview WORK/<G>/data PAGE OUT/anim_<G>.json PREV/<G> <PORT>` (ดูภาพด้วย Read)
   - ใน anim file: `"set":"hemonc"` · key ขึ้นต้น `anm-` · `sec` = id ของ section ของคุณ · `after` = หัวข้อ ### ใน md ของคุณ (ตรงตัว)
   - **ภาพเคลื่อนไหว ≥ 1 ภาพต่อภาวะ** (ภาวะที่กลไกซับซ้อนทำ 2 ได้) · **หลักจำสากล 1–3 อันต่อภาวะ** (ของจริงที่ใช้กันใน First Aid/USMLE/ตำรา — ค้นยืนยันด้วย WebSearch ถ้าไม่แน่ใจ ห้ามแต่งแล้วอ้างว่าเป็นสากล · ถ้าภาวะไหนไม่มีหลักจำสากลจริง ใช้หลักจำที่ย่อเองได้แต่ src ต้องบอก "ย่อเพิ่มเพื่อช่วยจำ — ไม่ใช่หลักจำมาตรฐาน")

## เนื้อหาแต่ละภาวะ ("ตึง ๆ" = ไล่ลึกทุกชั้น) md ภาษาไทยปนศัพท์อังกฤษ 3,000–6,000 ตัวอักษร มีหัวข้อ ### อย่างน้อยเหล่านี้
1. **ภาพรวม/นิยาม/ระบาดวิทยาสั้น ๆ** (บริบทไทยถ้ามี เช่น thalassemia, G6PD, HbE)
2. **ไล่กลไกเป็นลูกโซ่** ตั้งแต่ระดับยีน/โมเลกุล/เอนไซม์ → เซลล์ (RBC/ไขกระดูก) → อวัยวะ (ม้าม ตับ ไต ไขกระดูก) → ระบบ — ใช้ลูกศร → และตัวเลขสำคัญ
3. **ทำไมถึงมีอาการ/อาการแสดงนี้** — ตาราง | อาการ/สิ่งตรวจพบ | กลไก |
4. **ทำไมผลแล็บถึงออกมาแบบนี้** — MCV, retic, smear, iron study/ferritin/TIBC, LDH/bilirubin/haptoglobin, DAT, ค่าเฉพาะโรค พร้อมเหตุผลเชิงกลไกทีละค่า
5. **วินิจฉัย** (การตรวจยืนยันและกับดัก เช่น G6PD ตรวจตอนแตกอาจปกติเทียม, ferritin สูงจากการอักเสบ)
6. **รักษาตามกลไก** — แต่ละการรักษาตัดวงจรตรงไหน (ขนาดยาสำคัญตามแนวทางสากล)
7. **กับดักข้อสอบ/แยกโรค** สั้น ๆ
- ใช้ **ตัวหนา** กับคำสำคัญ · ตาราง markdown ได้ · " · " คั่นท่อนในย่อหน้าจะถูกตัดบรรทัดอัตโนมัติ
- ห้ามคัดลอกข้อความจากแหล่งใด เขียนเองทั้งหมด · ข้อมูลต้องถูกต้องตามตำรามาตรฐาน/แนวทางปัจจุบัน
- `items`: **MCQ 3 ข้อต่อภาวะ** stem ภาษาอังกฤษแบบ vignette 5 ตัวเลือก กระจายเฉลย · explain ไทย ≥ 400 ตัวอักษร อธิบายกลไก + ทำไมข้ออื่นผิด · ref list · nl จาก BASE/nl.json
- `pearls` 4–6 ข้อ (จำไปสอบ)
