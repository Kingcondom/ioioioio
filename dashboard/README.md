# MED421 Lectures — dashboard รวมทุกคาบบรรยาย

**artifact:** https://claude.ai/artifact/8ir2xCgMKC7Fn4MiE2a5AV (ต้นฉบับคือ `index.html` ในโฟลเดอร์นี้)

หน้าเดียวรวมคาบบรรยายของกลุ่มเรา 45 คาบ (14 ก.ย. – 22 พ.ย. 2569) จาก Google Calendar หน้าตาแบบแอปห้องสมุด (ตามภาพอ้างอิง Pinterest) มี 5 แท็บ

0. **วันนี้ทวนอะไร** (หน้าแรก) — บอกว่าวันนี้ควรทวนกี่คาบ คาบไหน เพื่อให้ทุกคาบได้ทวนครบเป้าก่อนสอบลงกอง 17 พ.ย.
   - เป้าทวนต่อคาบเลือกได้ 1 / 2 / 3 รอบ (ค่าเริ่ม 2) · ทวนคาบเดิมซ้ำห่างกันอย่างน้อย 3 วัน · วันที่ทวนได้ = วันนี้ถึง 16 พ.ย.
   - โควตาต่อวัน = จำนวนคาบต่อวันที่น้อยที่สุดที่จำลองทุกวันไปจนวันสอบแล้วทุกคาบได้ครบเป้า
     (คาบที่เรียนใกล้สอบเกินจะครบเป้า นับเท่าที่ทวนทัน เช่น Derm 11 พ.ย. ได้ 2 รอบ)
     นับจากรอบที่ทวน *ก่อน* วันนี้ จึงไม่ขยับระหว่างวัน · วันไหนไม่ได้ทวน วันต่อไปเกลี่ยโควตาใหม่ให้เอง
   - ลำดับ: เพิ่งเรียนวันนี้/เมื่อวาน → ยังขาดหลายรอบ → ไม่เคยทวน (ข้อสอบเก่าเยอะก่อน) → ทวนล่าสุดนานสุด
   - มีคาบที่กำลังจะเรียน (อ่าน Learn ก่อน), แผน 7 วันข้างหน้า และวันที่คาดว่าจะเคลียร์คาบค้าง/ครบเป้า
   - ปุ่ม ✓ ใช้บันทึกเดียวกับกล่องในแท็บสไลด์อาจารย์
   - **ปรับรายการวันนี้เอง**: ปุ่ม "เปลี่ยน" ในแต่ละคาบ → เลือกเรื่องอื่นมาแทน (ค้นหาได้ · แยก "ถึงรอบ/ค้างทวน" กับ "เรื่องอื่นที่เรียนแล้ว")
     หรือ "เลื่อนไปวันอื่น" ให้ระบบเติมเรื่องถัดไป · "+ ทวนเรื่องอื่นเพิ่ม" เพิ่มนอกโควตา · "กลับเป็นแผนอัตโนมัติ" ล้างที่ปรับ
     ใช้เฉพาะวันนี้ (`today:{d,skip,pin,add}` เก็บคู่กับ reviews ในเอกสารส่วนตัวและ localStorage) · แผน 7 วันคำนวณต่อจากรายการที่ปรับแล้ว

   กล่องเป็นสีเขียว (ทวนแล้ว) → ผ่านไป 3 วันเป็นสีส้ม (ถึงรอบทวน) · ยังไม่ทวน = ป้ายแดง · ยังไม่ถึงคาบ = กรอบประ
   กดกล่องเพื่อเปิดรายละเอียด: ประวัติการทวน, ไฟล์สไลด์ใน Google Drive (18 คาบ), Learn, Drill, อ่านคู่
2. **ตารางเรียน · Learn & Drill** — เรียงตามสัปดาห์ แต่ละคาบมีปุ่มเปิด **MED421 learn** และ **MED421 Ward Drill** ตรงคาบนั้น
3. **ครอบคลุม NL** — บทเรียนทั้งหมด (learn · Ward Drill · ห้องสมุดท่าอาจารย์ · บทข้างเตียงอื่น) ครอบคลุมเกณฑ์แพทยสภา 2567
   ฝั่งอายุรกรรม 321 หัวข้อแล้วกี่ % แยกรายระบบ รายระดับ (กลุ่ม 1–2 / 3) พร้อมลิงก์หลักฐานทุกข้อ
4. **แผนเติม NL** — ข้อเสนอ 38 บท (A1–C4) ที่ครอบหัวข้อ NL ที่เคยขาด 142 ข้อ (แต่ละรหัสอยู่ในข้อเสนอเดียว ทำครบ = 100%)
   การ์ดนับเฉพาะรหัสที่ยังขาดตอนนี้ (หลังรวม Salmon NL เหลือ 50) · บท B/C ที่ไม่เหลือรหัสให้ปิดย้ายไปกล่อง "ไม่ต้องทำแล้ว"
   · กลุ่ม A แสดงจนกว่าคาบนั้นจะมีบท Learn (ช่วยสอบลงกองแม้ NL ครบแล้ว)
   - A1–A20 = บท Learn ของคาบในตารางที่ยังไม่มีบทเรียน · B1–B14 = บทใหม่นอกตาราง · C1–C4 = เติมหัวข้อย่อยในบท Learn เดิม
   - กด เอา / ไม่เอา ทีละบท หัวหน้าแสดง % ที่จะได้ถ้าทำบทที่เลือก · ปุ่มล้างการเลือก (กดคืนได้) · ป้าย "แนะนำ" 11 บท ปิดได้ 29 หัวข้อ
   - ที่เลือกเก็บใน db เอกสารรวม `plans/nl-lessons` รูปแบบ `{picks: {"A1": "y", "B2": "n"}}` ให้ Claude อ่านด้วย ArtifactData

## ลิงก์ตรงเข้าคาบ (deep link)

artifact ส่งต่อเฉพาะ `#token` ธรรมดา (ตัวอักษร ตัวเลข `.` `_` `~` `-`) เข้าไปถึงหน้าเว็บ จึงใช้รูปแบบ

```
<learn>#<ชุด>-<คาบ>     เช่น #cardio-13 · #gi-27.10 (คาบ "27/10" ใช้ . แทน /) · #endo (ทั้งชุด)
<drill>#<ชุด>-<lec>     เช่น #nephro-14 · #neuro-N02 · #chest-TB2 · #mock-M07 · #derm (ทั้งชุด)
<salmon>#<ชุด>-<คาบ>    เช่น #derm-05 · #hemato-10 · #resp-07
```

Salmon NL ใส่โค้ดรับลิงก์แล้ว (13 ต.ค. 2569 · Version 5) ด้วย `python3 patch_deeplinks.py salmon <index.html ของ Salmon> <ไฟล์ออก>`
engine เดียวกับ learn จึงใช้แพตช์ชุดเดียวกัน · #derm-05 และ #hemato-10 เลื่อนไปถึงคาบ
**ถ้า publish Salmon NL ใหม่จากที่อื่น ต้องมีโค้ดส่วนนี้ด้วย** ไม่อย่างนั้นลิงก์จะเปิด Salmon ที่หน้าล่าสุดที่ดูไว้แทน

- **learn** → เลือกชุด เปิดหน้าภาพรวม กางคาบนั้นในแถบซ้าย แล้วเลื่อนไปที่การ์ดของคาบ
- **drill** → เลือกชุด โหมด "ข้อสอบใหม่" กรองเฉพาะ lecture นั้น (ถ้ามีแต่ในคลังเก่าจะสลับเป็นโหมดคลังเก่า)

โค้ดที่เพิ่มอยู่ใน `patch_deeplinks.py` (เพิ่มเมื่อ 13 ต.ค. 2569 · learn Version 20 · drill Version 11)
**ถ้า publish learn หรือ drill ใหม่จาก branch อื่น ต้องมีโค้ดส่วนนี้ด้วย** ไม่อย่างนั้นปุ่มใน dashboard จะเปิดแค่หน้าแรก
(ไม่พัง แต่ไม่กระโดดไปคาบ) — `readHash()/landHash()` + `id='lec-…'` ในการ์ดคาบของ learn และ `applyHash()` ท้ายสคริปต์ของ drill

แพตช์ learn/salmon ตอนนี้มีบรรทัด `document.fonts.ready` ใน `landHash()` ที่เลื่อนไปการ์ดคาบซ้ำหลังฟอนต์โหลดเสร็จ
(ฟอนต์มาทีหลังทำให้ความสูงด้านบนขยับ) — Salmon NL Version 5 มีแล้ว แต่ **learn Version 20 แพตช์ไว้ก่อนเพิ่มบรรทัดนี้ จึงยังไม่มี**
ลิงก์เข้าคาบของ learn ยังใช้ได้ แต่บางครั้งหยุดก่อนถึงการ์ด
- แพตช์รันได้กับหน้าที่ **ยังไม่แพตช์** เท่านั้น (รันซ้ำบนหน้าที่แพตช์แล้ว `sub()` จะ assert ไม่ผ่าน) → ถ้า publish learn ใหม่จากต้นฉบับ แพตช์จะใส่บรรทัดนี้ให้เอง
- ถ้าจะเติมให้ learn Version 20 ตอนนี้ ให้ใส่บรรทัดนั้นเองต่อจาก `el.scrollIntoView(...)` ใน `landHash()` (ดูบรรทัด 54 ของ `patch_deeplinks.py`)
(เช็ก ณ 13 ต.ค. 2569: dashboard ที่ publish ตรงกับ `index.html` ทุกบรรทัด · learn/drill/Salmon ที่ publish มีโค้ดรับลิงก์ครบ)

## MED421 learn บันทึกความคืบหน้าในบัญชี

ตั้งแต่ learn Version 22 (13 ต.ค. 2569) ความคืบหน้าใน learn — หัวข้อที่เรียนจบ คำตอบข้อเช็ค โน้ต MEQ/OSCE และการประเมินตัวเอง —
บันทึกในบัญชีของแต่ละคน (capability `db` + `user`) ซิงก์ทุกเครื่อง · แถบบนบอกสถานะ "บันทึกในบัญชี" / "บันทึกในเครื่องนี้"
- เอกสารส่วนตัว `data/users/<id>/learn` = `{done, ans, rate}` และ `data/users/<id>/learn-notes` = `{notes}` (แยกเพราะเอกสารละไม่เกิน 256 KiB)
- localStorage ยังเก็บสำเนาไว้ (`med421-learn-v1` + สถานะซิงก์ `med421-learn-v1:sync`)
- เชื่อมบัญชีครั้งแรก: เครื่องที่ยังไม่เคยซิงก์หรือมีของค้างจะรวมกับของในบัญชี · เครื่องที่ซิงก์แล้วใช้ของในบัญชี (ล้างคำตอบจากเครื่องหนึ่ง อีกเครื่องตาม)
  · เบราว์เซอร์ที่เคยซิงก์กับบัญชีอื่นจะไม่เอาของเดิมไปปน
- โค้ดอยู่ใน `patch_learn_sync.py` (รันกับหน้า learn ที่ยังไม่แพตช์ แล้ว publish พร้อม `capabilities: {db:{}, user:{}}`)
  **ถ้า publish learn ใหม่จากที่อื่น ต้องมีโค้ดส่วนนี้และ capability ด้วย** ไม่อย่างนั้นจะกลับไปเก็บแค่ในเครื่อง
- ทดสอบกับ db จำลอง: 2 เครื่องบัญชีเดียวกันเห็นของกันและกัน · ล้างหัวข้อแล้วอีกเครื่องตาม · รีโหลดไม่ฟื้นคำตอบที่ล้าง ·
  ไม่ล็อกอินเก็บในเครื่อง · สลับบัญชีไม่ปนกัน · ความคืบหน้าเดิมในเครื่องถูกรวมเข้าบัญชีครั้งแรก
