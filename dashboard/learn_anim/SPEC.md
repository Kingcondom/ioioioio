# งาน: กลไกการเกิดโรคแบบภาพเคลื่อนไหว + หลักจำ สำหรับเว็บเรียน MED421 learn

นักศึกษาแพทย์ปี 4 (ไทย) เตรียมสอบ ใช้เว็บ "MED421 learn" อ่านเนื้อหาแยกตามคาบเรียน
เขาขอ: **"pathophysiology แบบมี animation ลงในทุกบทที่มีเนื้อหา และหลักจำที่คนทั่วไปใช้จำเรื่องนั้น"**

คุณรับผิดชอบ **ชุด (set) เดียว** ตามที่ระบุในคำสั่ง ทำให้ครบ **ทุกคาบ (lecture)** ในชุดนั้น
เขียนผลลัพธ์เป็นไฟล์ JSON ไฟล์เดียว ห้ามแก้ไฟล์อื่นใด ห้าม publish ห้าม commit

## แหล่งข้อมูล
- เนื้อหา: `DATA/<set>.json` = list ของคาบ `{lec, title, subtitle, objectives, sections:[{id, title, md, pearls, figs, ...}], ...}`
  - `md` = markdown ภาษาไทย หัวข้อย่อยเป็น `### ...` / `#### ...` · `figs` = แผนภาพ SVG นิ่งที่มีอยู่แล้ว (ดูเป็นตัวอย่างสไตล์ได้ อย่าทำซ้ำของเดิม)
  - อ่านด้วย python (`json.load`) ดูเฉพาะที่ต้องใช้ ไฟล์ใหญ่ อย่า cat ทั้งไฟล์
- ตัวอย่างที่ถูกต้อง: `SPEC_DIR/example.json` (pulsus paradoxus ใน tamponade + Beck's triad) และภาพผลลัพธ์ใน `SPEC_DIR/prev/*.png`

## สิ่งที่ต้องทำต่อคาบ
1. **ภาพเคลื่อนไหวกลไก 2–4 ภาพต่อคาบ** (คาบใหญ่ ≥12 หัวข้อ ทำ 3–4) เลือกกลไกแกนกลางที่ออกสอบและเข้าใจยากถ้าอ่านอย่างเดียว
   - ตัวอย่างแนวคิด: ลำดับเหตุการณ์ (trigger → กลไก → ผลทางสรีรวิทยา → อาการ/สิ่งตรวจพบ/ผลแล็บ), วงจรป้อนกลับ, เปรียบเทียบปกติ vs โรค, ยาไปตัดวงจรตรงไหน
   - คาบที่ไม่ใช่โรคโดยตรง (เช่น ABG, LFT, imaging, หัตถการ LP) ให้ทำกลไกสรีรวิทยา/พยาธิสรีรวิทยาที่อธิบายผลตรวจ (เช่น การชดเชยกรด-ด่าง, เมแทบอลิซึมบิลิรูบิน, การไหลของ CSF/papilledema, การอุดตันทางเดินปัสสาวะ → hydronephrosis)
   - วางใน section ที่เนื้อหาตรงที่สุด (`sec`) และระบุ `after` = ข้อความหัวข้อ `###`/`####` ใน md ของ section นั้น **ตรงตัวอักษร** (ไม่ใส่ #) ภาพจะไปอยู่ท้ายหัวข้อนั้น · ใส่ `""` = ท้าย section
   - section หนึ่งไม่เกิน 2 ภาพ กระจายไปตามหัวข้อ
2. **หลักจำ 3–8 อันต่อคาบ** = mnemonic ที่ **คนทั่วไปใช้กันจริง** (First Aid/USMLE, ตำรามาตรฐาน, ที่นักศึกษาแพทย์ไทยใช้กันแพร่หลาย) สำหรับเรื่องในคาบนั้น
   - **ห้ามแต่งขึ้นเองแล้วอ้างว่าเป็นที่นิยม** · ไม่แน่ใจให้ค้นยืนยันด้วย WebSearch · ถ้าเรื่องไหนไม่มีหลักจำที่ใช้กันจริง ข้ามได้
   - ถ้าจำเป็นต้องมีหลักจำที่ไม่ใช่มาตรฐาน (เช่น ย่อเองให้จำง่าย) ใส่ `src` ว่า "ย่อเพิ่มเพื่อช่วยจำ — ไม่ใช่หลักจำมาตรฐาน" (ใช้น้อยที่สุด)
   - เนื้อหาต้อง **สอดคล้องกับ md ของคาบ** (เกณฑ์/ตัวเลขของอาจารย์) ถ้าหลักจำสากลต่างจากที่อาจารย์สอน ให้บอกใน `note`
   - วางใน section ที่ตรงเรื่อง (`sec`)
3. ความถูกต้องทางการแพทย์สำคัญที่สุด · ใช้ตัวเลข/กลไกตามเนื้อหาในคาบเป็นหลัก ไม่ขัดกับ md

## รูปแบบไฟล์ผลลัพธ์ `OUT/<set>.json`
```json
{"set":"<set>",
 "items":[{"sec":"<section id>","after":"<หัวข้อใน md หรือ ''>",
           "anim":{"key":"<a-z0-9- ไม่ซ้ำ เช่น c04-pulsus>","title":"<ชื่อภาพ ไทยปนศัพท์อังกฤษ>",
                   "svg":"<svg ...>...</svg>",
                   "steps":[{"t":"<ชื่อขั้นสั้น ๆ>","cap":"<คำอธิบายขั้นนี้ 1–2 ประโยค ใช้ **ตัวหนา** ได้>"}, ...]}}],
 "mnem":[{"sec":"<section id>","name":"<ชื่อหลักจำ เช่น MUDPILES>","what":"<ใช้จำอะไร>",
          "lines":[["M","Methanol"],["U","Uremia"], ...],
          "note":"<ข้อควรระวัง/ความต่างจากที่อาจารย์สอน (ไม่บังคับ)>","src":"<ที่มา เช่น First Aid USMLE Step 1 / ตำรา ... / ใช้กันทั่วไปในหมู่ นศพ.ไทย>"}]}
```
- key ขึ้นต้นด้วยตัวย่อคาบ เช่น `c04-`, `n14-`, `dm-` ไม่ซ้ำกันในไฟล์
- steps 3–7 ขั้น · `t` ≤ 70 ตัวอักษร · `cap` ≤ 360 ตัวอักษร · ภาษาไทยเป็นหลัก ศัพท์แพทย์อังกฤษได้
- `lines` คู่ [คำ/ตัวอักษร, ความหมาย] ใช้ `**ตัวหนา**` ในความหมายได้ (เช่น `"**D**istended neck veins"`)

## กติกา SVG (ตัวตรวจจะไม่ผ่านถ้าผิด)
- `<svg viewBox="0 0 W H" role="img" aria-label="บรรยายภาพเป็นไทย" xmlns="http://www.w3.org/2000/svg">` · W 380–460 (จอมือถือ), H ≤ 460 · ห้ามใส่ width/height
- **ห้ามใส่สีตายตัว** (fill="#..", stroke="red", style สี) — ใช้ class ของธีม (ปรับตามโหมดสว่าง/มืดอัตโนมัติ):
  - กล่อง/รูปทรง (พื้น+เส้น): `bx` (พื้นผิว) `sk` (เทาอ่อน) `ac` (แดงเลือดหมู-แบรนด์) `ok` (เขียว) `bad` (แดง) `ms` (เหลือง/ส้ม) `wa` (ฟ้า)
  - ทึบไม่มีเส้น: `acf okf badf msf waf inkf muf ruf paf` (ใช้กับจุด/อนุภาค/แถบ)
  - เส้นอย่างเดียว: `ln` (เทาเข้ม) `lmu` `lac` `lok` `lbad` `lms` `lwa` `lru` · ความหนา `w2 w3 w5` · เส้นประ `da` · จุดไข่ปลา `dt` · ไม่มีเส้น `ns`
  - ตัวอักษร: ขนาด `lg`(15) ค่าปกติ 13 `sm`(11.5) `xs`(10.5) · `b` ตัวหนา · `mid` `end` จัดกลาง/ชิดขวา · สี `mu i2 tac tok tbad tms twa tpa`
  - ลูกศร: `marker-end="url(#ah)"` และ `#ah-ac #ah-ok #ah-bad #ah-ms #ah-wa #ah-mu` เท่านั้น
- ห้าม `<script> <style> <foreignObject> <image> <a> <use>`, ห้าม on*, ห้ามตั้ง `id`, ห้าม href ภายนอก, ห้าม class อื่นนอกจากรายการนี้
- ข้อความ: ภาษาไทยกว้างประมาณ 7–8 px ต่อตัวอักษรที่ขนาด 13 · กะระยะให้ **ไม่ทับกันและไม่ล้นขอบ** (ตรวจจากภาพ preview)

## กลไกขั้นของภาพเคลื่อนไหว
- ทุก element ที่ไม่มี data-* = โครงพื้นฐานเห็นตลอด (ขั้น 1 ขึ้นไป)
- `data-s="k"` = โผล่ตั้งแต่ขั้น k (ค่อย ๆ จางเข้า) · `data-x="k"` = หายไปตั้งแต่ขั้น k (ใช้แทนสภาพปกติด้วยสภาพโรค)
  - ทุกขั้น 2..N ต้องมี element `data-s` ของตัวเองอย่างน้อย 1 ชิ้น · ห่อหลายชิ้นด้วย `<g data-s="k">` ได้
- การเคลื่อนไหวต่อเนื่อง (ใส่ใน class): `fl` เส้นประไหลตามทิศของ path (การไหลของเลือด/สาร/สัญญาณ) · `fl rv` ไหลย้อน · `fl sl` ไหลช้า · `pl` กะพริบเบา ๆ (จุดที่เกิดเหตุ)
  - **อย่าใส่ `pl` บน element ที่มี data-s** — ห่อด้วย `<g data-s="k">` แล้วใส่ pl กับลูกข้างใน
- SMIL ใช้ได้เพื่อให้มีชีวิต: `<circle r="4" class="badf"><animateMotion dur="2.4s" repeatCount="indefinite" path="M..."/></circle>` (อนุภาคไหลตามทาง เช่น เม็ดเลือด ไอออน เชื้อโรค) · `<animate attributeName="r|opacity|height|y" values="..." dur="..." repeatCount="indefinite"/>` (เช่น ห้องหัวใจบีบ ถุงลมพอง) — ใช้ path ใส่ตรง ๆ ไม่ใช้ mpath/id
- ตัวเล่นเล่นอัตโนมัติขั้นละ ~3–8 วินาทีตามความยาว cap วนรอบ มีปุ่มกดทีละขั้น และ **ไม่เล่นเองสำหรับผู้ใช้ที่ปิด motion** — ภาพแต่ละขั้นต้องอ่านรู้เรื่องแม้ภาพนิ่ง
- ขั้นสุดท้ายควรสรุปภาพรวม (โยงไปสิ่งที่ตรวจพบ/ข้อสอบชอบถาม)

## ตรวจงาน (ต้องทำจนผ่าน)
```
cd TOOLS && python3 anim_tool.py check DATA OUT/<set>.json
cd TOOLS && python3 anim_tool.py preview DATA PAGE OUT/<set>.json PREV/<set> <PORT>
```
- preview ถ่ายภาพทุกขั้น (สว่าง) + ขั้นสุดท้าย (มืด) + กล่องหลักจำ ลงโฟลเดอร์ `PREV/<set>` — **เปิดดูภาพด้วย Read** อย่างน้อยขั้นสุดท้ายและภาพมืดของทุกภาพเคลื่อนไหว แก้ข้อความทับ/ล้นขอบ/ลูกศรชี้ผิดที่
- ใช้ PORT ที่ให้มาเท่านั้น (รันพร้อมกับคนอื่น)
- เขียนไฟล์ JSON ด้วย python (`json.dump(..., ensure_ascii=False, indent=1)`) เพื่อกัน escape ผิด แนะนำเขียนสคริปต์สร้างไฟล์ใน `WORK/<set>/` แล้วรัน

จำนวนภาพ/หลักจำต่อคาบ, รายชื่อหลักจำ + ที่มา, จุดที่ไม่แน่ใจทางการแพทย์ (ถ้ามี), ยืนยันว่า check ผ่านและดู preview แล้ว
