# งาน: ชุดข้อสอบรายคาบสำหรับ MED421 Ward Drill (ข้อสอบเตรียมสอบลงกองอายุรศาสตร์ ปี 4)

นักศึกษาแพทย์ไทยใช้ "Ward Drill" ทำข้อสอบแยกตามคาบเรียน คาบที่เพิ่งได้ชุดเต็มจากสไลด์ (DM, WBC, ECG) มี ~30 MCQ + MEQ/OSCE
แต่หลายคาบที่มีสไลด์แล้วยังมีแค่ข้อทั่วไปไม่กี่ข้อ — คุณทำชุดเต็มให้ **คาบเดียว** ตามคำสั่ง

## แหล่งเนื้อหา (ใช้ตามลำดับนี้)
1. **บทเรียน Learn ของคาบนี้** (สรุปจากสไลด์อาจารย์แล้ว ละเอียด มีหัวข้อ "ที่อาจารย์เน้นในสไลด์"):
   `LEARN/<learnset>.json` → list ของคาบ หา `lec` ตามที่ให้ → `sections[].md` / `pearls` / `nl` (รหัส NL ของแต่ละหัวข้อ) / `source`
   อ่านด้วย python เฉพาะคาบนั้น อย่า cat ไฟล์ทั้งไฟล์
2. **สไลด์จริงใน Google Drive** (ถ้ามี fileId): ลอง `mcp__Google_Drive__read_file_content` (โหลดผ่าน ToolSearch "select:mcp__Google_Drive__read_file_content") ถ้าไฟล์ใหญ่จนอ่านไม่ได้ ใช้ Learn อย่างเดียวได้
3. ความรู้มาตรฐาน/แนวทางเวชปฏิบัติ — ใช้เติมได้ แต่ **ห้ามขัดกับที่อาจารย์สอน** (ถ้าต่าง ให้ยึดอาจารย์และบอกใน explain)

## ตัวอย่างรูปแบบที่ต้องเลียนแบบ
`SPEC_DIR/examples.json` = ข้อจากชุด DM (E05) ที่ทำไว้แล้ว: MCQ 3 ข้อ + MEQ 1 + OSCE 1 — ดูโทน ความยาว โครงสร้าง explain

## ทำอะไร
- **MCQ 26–32 ข้อ** ครอบคลุมทุกหัวข้อ (section) ของคาบ ตามน้ำหนักที่อาจารย์เน้น
  - stem ภาษาอังกฤษ เป็น clinical vignette สั้น–กลาง (อายุ เพศ อาการ PE แล็บ) แบบข้อสอบลงกอง/NL · มีข้อแบบ "next step", "most likely diagnosis", "mechanism", "drug of choice", "interpret lab" ผสมกัน · ไม่ต้องยาวทุกข้อ
  - choices **5 ตัวเลือก** ภาษาอังกฤษ เป็นไปได้ทั้งหมด (distractor สมจริง) ไม่ใช้ "all of the above"
  - `answer` = index 0–4 · **กระจายตำแหน่งเฉลย** ให้ใกล้เคียงกัน
  - `explain` ภาษาไทย (ศัพท์แพทย์อังกฤษได้) 400–1,200 ตัวอักษร: **กลไก/เหตุผล** ว่าทำไมข้อถูกถูก แล้ว "ทำไมข้ออื่นผิด" ทีละตัวเลือกสั้น ๆ · ใช้ **ตัวหนา** ได้ · ขึ้นบรรทัดด้วย \n · ตารางแบบ markdown ได้
  - `pearl` ไทยสั้น 1 บรรทัด (จำไปสอบ)
  - `ref` = list เช่น `["สไลด์ อ.<ชื่อ> — <หัวข้อ>"]` (+ แนวทางสากลถ้าใช้)
  - `nl` = list รหัส NL **ที่มีอยู่ใน `SPEC_DIR/nl_codes.json` เท่านั้น** — เอาจาก `nl` ของ section Learn ที่ข้อนั้นอิง
  - `topic` ภาษาอังกฤษสั้น ๆ
- **MEQ 1–2 ข้อ** (vignette ไทยแบบเคสจริง CC/PI/PH/PE/Lab + questions 5–6 ข้อย่อย {q,a} มีคะแนนในวงเล็บ เฉลยละเอียด)
- **OSCE/SAQ 1 ข้อ** ถ้าคาบนี้มีทักษะที่สอบได้ (station, instruction, answer เป็นเกณฑ์ให้คะแนน/ตาราง)
- **ห้ามลอกข้อที่มีอยู่แล้ว** — ดูข้อเดิมของหัวข้อนี้ใน `SPEC_DIR/existing_<set>.json` (stem ห้ามซ้ำ ทำมุมใหม่)
- ความถูกต้องทางการแพทย์สำคัญที่สุด: ตัวเลข เกณฑ์ ขนาดยา ต้องตรงกับเนื้อหาของคาบ
